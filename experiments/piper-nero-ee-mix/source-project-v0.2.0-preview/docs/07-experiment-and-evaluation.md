# 07 — 实验与评估

## 1. 必须保留的基线

至少比较：
- NERO-only EF：原始 NERO EE 训练路线。
- NERO + Piper EE：本项目 `nero_ee_sb` 混训路线。

尽量保持模型初始化、训练预算、NERO 测试任务、控制器和评估条件一致。

## 2. 主要验收指标

| 类别 | 指标 |
|---|---|
| 任务效果 | NERO 真机成功率、完整任务完成率 |
| 过程表现 | 每阶段成功率、失败发生阶段 |
| 运动质量 | EE 位置误差、姿态误差、动作平滑性 |
| IK | IK 成功率、求解耗时、关节限位触发次数 |
| 稳定性 | 多次重复执行的方差、异常状态恢复 |
| 推理 | 单次推理延迟、chunk 执行延迟 |
| Step Flag | 阶段切换检测 precision/recall、误触发率 |

## 3. 实验纪律

- 固定 NERO 测试集，不将训练数据作为主要验收集。
- 每次真机试验记录模型 checkpoint、配置、prompt、初始状态、相机图像、动作 chunk、IK 结果和最终结果。
- 分开记录“模型预测错误”“IK 不可达”“控制执行失败”“环境/感知异常”。
- 不把单次成功写成稳定成功率。
- Piper 的提升必须体现在 NERO 测试结果上。
