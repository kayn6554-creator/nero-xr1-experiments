## 数据与动作

基线：261 条、94125 帧。失败前缀：75 条、10917 帧，仅保留失败步骤之前的部分；失败发生在第一步的轨迹跳过。M2 抽稀后 74441 个样本。新增五任务 168 条、36288 帧；M3 共 11 个数据目录（8 个成功任务目录 + 3 个失败前缀目录），抽稀后 107337 个样本。上述计数来自历史记录/配置生成结果，本次未获得数据集，未重新计算。

抽稀只减少训练起点，不删除动作轨迹时间轴。静止判据：最快关节 < 2°/s 且相邻夹爪指令变化 < 1 mm；静止段保留开头 10 帧（第 3 步 20 帧）及结尾 10 帧。

60 维容器保持不变：

| 布局 | 有效通道（0 起始） |
|---|---|
| `nero_joint` | 0～6：关节差；7：夹爪 |
| `nero_ee` | 0～2：当前法兰坐标系中的位置差；3～5：相对旋转向量；6：夹爪；7：j3 差 |
| `nero_joint_sb` | 0～7 同关节版；8：未来帧步骤标签与块起点标签不同则为 1，否则为 0 |

EF 的输入状态仍是七关节 + 夹爪，不是末端状态。M5 标记均值/标准差为 0.5/0.5，训练有效 mask 包含索引 8。其输出是连续回归量，不是校准概率。

## M5：必须区分的两个方案

11-12 PDF 曾描述将跨步动作替换为本步末尾停留的方案。实际上传代码为 `apply_m5sb.py`：保留自然跨步动作，只增加步骤标记。实际运行目录为 `m5-stepflag`。

待开发推理协议：标记判断边界，边界帧及之后复制前一帧的七关节和夹爪；首帧触发时保持请求中的当前状态；回包说明本步最后保留帧；逐请求记录原始标记与判断。30×8 动作接口保持不变。阈值 0.5/连续两帧是待验证初值，不是已验证最优参数。手动切换步骤，不自动声称任务成功。该标签没有额外监督第 4 步的整段任务终止。
